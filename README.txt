THE GATES OF OLYMPUS — GitHub Pages

1. Create a PUBLIC GitHub repository (e.g. gates-of-olympus).
2. Upload ALL CONTENTS of this ZIP (index.html, script.js, style.css, missions.json, and the assets folder) to the repository root.
3. In Settings > Pages, choose Deploy from a branch > main > /(root), then Save.
4. Wait for the published GitHub Pages URL.
5. Test all gates with ?preview=1 appended BEFORE any # fragment, e.g. https://username.github.io/gates-of-olympus/?preview=1
6. Remove ?preview=1 for the normal daily unlock view.

Unlock dates: December 1–24, 2026 at midnight Europe/Berlin time. This is a CLIENT-SIDE visual lock, not secure access control; users may access mission text via the JSON file. The preview link is NOT a password.

Note: The supplied 24 mission Word files are preserved as supplied, except the introductory global foreword in Mission_01.docx is not repeated on Mission 01 page. Missions 01–12 were marked as reconstructed in the source file.

The background is an available Olympus illustration from the existing project; if it is not the final preferred one, replace assets/olympus.webp with the preferred image converted to WEBP.
